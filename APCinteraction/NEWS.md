# APCinteraction 0.1.0

* Initial CRAN release.
* Added `APCSSA()` and `APCSSM()` for nonparametric interaction tests in balanced two-way ANOVA designs using all possible crossed comparisons.
* Added `sim_nullAPCSSA()` and `sim_nullAPCSSM()` for simulating null distributions with parallel computation support.
* Added `save_null()` for saving simulated null distributions locally.
* Pre-computed null distributions for example designs are bundled; additional distributions are available via the companion package `APCinteractionData`.
